# eEPUB Calibre連携ヘルパー

[eEPUB](https://eepub.jp)からKindle形式(KFX / MOBI / AZW3)の本を取り込むときに、お使いのMac/Windowsに
インストール済みの[Calibre](https://calibre-ebook.com/)を呼び出してEPUBに変換するための、小さなローカル常駐プログラムです。

## これは何をするもの？

eEPUBはブラウザだけで動くアプリ(PWA)です。ブラウザは仕組み上、パソコンにインストールされている
Calibreのような外部プログラムを直接起動できません。そこでこのツールを別途起動しておくと、
eEPUBのタブから`http://127.0.0.1:47821`という自分のパソコンの中だけのアドレス経由でCalibreを
呼び出せるようになり、KFXファイルなどの取り込みができるようになります。

- **外部にファイルを送信しません**。変換はすべてお使いのパソコンの中で完結します(このツールが行うのは
  「あなたのパソコン上のeEPUBタブ」と「あなたのパソコン上のCalibre」を橋渡しするだけです)
- **アクセスできるのはeepub.jpとlocalhostだけ**に制限しています。無関係なサイトから勝手に使われることはありません
- ソースコードは全部このフォルダの中にあります(`server.mjs`が本体、150行程度です)。何をしているか自分の目で確認できます

## 必要なもの

1. **Node.js** … <https://nodejs.org/> からインストール(LTS版でOK)
2. **Calibre** … <https://calibre-ebook.com/download> からインストール

どちらもインストールするだけで、特別な設定は不要です(PATHへの追加もインストーラーが自動でやってくれます)。

## 使い方

1. このフォルダごとダウンロード・展開する
2. **Windows**: `start.bat` をダブルクリック
   **Mac**: `start.command` をダブルクリック
   (初回だけ少し時間がかかります。裏で`npm install`が自動で走ります)
3. 「eEPUB Calibre Helper」というタイトルのウィンドウが開いたままになります。これが起動中の合図です
4. そのままeEPUB([eepub.jp](https://eepub.jp))のタブに戻り、いつも通り本を追加してください。KFX/MOBI/AZW3ファイルを
   選ぶと、自動でこのヘルパー経由の変換が試されます
5. 使い終わったら、ウィンドウを閉じればヘルパーは停止します(次に使うときはまた`start.bat`/`start.command`から)

### Macで「開発元を確認できません」と出た場合

`start.command`を右クリック→「開く」を選ぶと、1回だけ確認ダイアログが出ますが実行できます
(Appleの公証を受けていない配布物のため、初回のみこの手順が必要です)。

## うまくいかないとき

| 症状 | 原因/対処 |
|---|---|
| 「Node.js が見つかりませんでした」 | [nodejs.org](https://nodejs.org/)からインストールしてください |
| eEPUB側でKFXが「非対応」のまま | このヘルパーを起動できているか確認してください。起動中は`http://127.0.0.1:47821/health`をブラウザで開くと状態が見られます |
| 変換が「失敗しました」になる | お使いのCalibreがそのファイル形式・DRMに対応していない可能性があります。**このヘルパー自体はDRM解除を一切行いません** — Calibre側の設定次第で結果が変わります |
| ポート47821が使用中というエラー | 他に何かがそのポートを使っています。`calibre-helper/server.mjs`先頭の`PORT`を書き換えるか、環境変数`PORT`を指定して起動してください |

## 補足: DRMについて

このツールはCalibreの`ebook-convert`コマンドをそのまま呼び出すだけで、DRM(コピー防止)を解除する機能は
一切実装していません。お使いのCalibreがDRMを解除できる状態(例: 何らかのプラグインを導入済み)であれば
結果的に変換できてしまうこともありますが、それはお使いのCalibre環境の話であり、このツールが
DRM解除を行っているわけではありません。ご自身が正当な権利を持つ本の、私的なフォーマット変換の範囲でご利用ください。
